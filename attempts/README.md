## Rule

One file should represent one coherent route or one clearly scoped continuation of a route. Do not turn a single file into an unbounded notebook covering unrelated ideas.

Historical attempts are never deleted simply because they failed. Mark them `DEAD_END`, `INVALID`, or `SUPERSEDED` and document why.

Use [`../templates/ATTEMPT.md`](../templates/ATTEMPT.md) for new records.
