## Question / goal

Starting from `A-20260820-001`, can an explicit low-degree shift filter remove deterministic growth from the generalized prime-Laguerre sequence while preserving the exponential signature of any nontrivial zero with `Re(rho)>1/2`?

The original plan was to suppress the completed-xi `n log n` trend. During the derivation a more basic obstruction appeared first: at any generalized center `s0>1`, the raw prime-Laguerre trace contains a deterministic exponential contribution caused solely by the pole of `zeta(s)` at `s=1`. A raw subexponential bound is therefore impossible even under RH.

This attempt hard-cuts the target from the raw prime trace to its **exact pole-subtracted discrepancy trace**.

## Mathematical setup

Fix a real center

```text
s0 > 1,
A = 2 s0 - 1,
q = -s0/(s0-1).
```

Use the Cayley map from `A-20260820-001`:

```text
s(z) = s0 + A z/(1-z)
     = [s0 + (s0-1)z]/(1-z),

z(s) = (s-s0)/(s+s0-1).
```

The open unit disk maps exactly to `Re(s)>1/2`.

Define the absolutely convergent fixed-`n` prime-Laguerre sequence

```text
P_n(s0)
 = A sum_{m>=2} Lambda(m) m^(-s0)
     L_(n-1)^(1)(A log m).
```

By `C-0006`, for sufficiently small `|z|`,

```text
sum_{n>=1} P_n(s0) z^(n-1)
 = -s'(z) zeta'(s(z))/zeta(s(z)).
```

## Derivation / argument

### Step 1 — locate the zeta pole in the z-plane

The pole `s=1` maps to

```text
z1 = z(1)
   = -(s0-1)/s0
   = 1/q.
```

Because `s0>1`,

```text
|z1| = (s0-1)/s0 < 1,
|q|  = s0/(s0-1) > 1.
```

Therefore the raw zeta logarithmic derivative has a singularity strictly inside the disk even if RH is true. Its Taylor coefficients must contain exponential growth at rate `|q|^n`.

This immediately corrects the raw target proposed at the end of `A-20260820-001`: `P_n(s0)` itself cannot be subexponential.

### Step 2 — compute the pole contribution exactly

DLMF records that `zeta` has a simple pole at `s=1` with residue `1`. Thus

```text
zeta'(s)/zeta(s) = -1/(s-1) + analytic term near s=1.
```

The coefficient sequence generated by the pole term is obtained from

```text
H(z) = s'(z)/(s(z)-1).
```

Since

```text
s'(z) = A/(1-z)^2,

s(z)-1 = [(s0-1)+s0 z]/(1-z),
```

we get

```text
H(z)
 = A / [(1-z)((s0-1)+s0 z)]
 = 1/(1-z) + s0/[(s0-1)+s0 z].
```

Expanding at `z=0` gives

```text
H(z) = sum_{n>=1} h_n z^(n-1),

h_n = 1 - q^n,
q   = -s0/(s0-1).
```

Because `|q|>1`, this is the deterministic exponential mode hidden in the raw prime trace.

### Step 3 — hard-cut to the pole-subtracted sequence

Define

```text
S_n(s0) = P_n(s0) - (1-q^n).
```

Now consider

```text
Z_*(s) = (s-1) zeta(s).
```

`Z_*` is analytic at `s=1` and nonzero there. Direct differentiation gives

```text
d/dz log Z_*(s(z))
 = s'(z) [1/(s(z)-1) + zeta'(s(z))/zeta(s(z))]
 = H(z) - sum_{n>=1} P_n z^(n-1)
 = -sum_{n>=1} S_n z^(n-1).
```

Thus `S_n` is not a heuristic subtraction. It is exactly the Taylor-coefficient sequence of the logarithmic derivative of the pole-regularized zeta function under the Cayley map.

### Step 4 — exact RH-equivalent root-growth criterion

Inside `Re(s)>1/2`, the function `Z_*(s)` has no trivial zeros. Its zeros there are precisely nontrivial zeta zeros with `Re(rho)>1/2`.

Therefore

```text
G(z) = d/dz log Z_*(s(z))
```

is analytic throughout `|z|<1` if and only if there is no nontrivial zero with real part greater than `1/2`.

By the functional equation symmetry `rho -> 1-rho`, absence of zeros with `Re(rho)>1/2` is equivalent to RH.

By the Cauchy-Hadamard radius formula applied to

```text
G(z) = -sum_{n>=1} S_n z^(n-1),
```

we obtain the exact criterion

```text
RH
<=> limsup_{n->infinity} |S_n(s0)|^(1/n) <= 1.
```

Equivalently, the weakest natural exponential-rate target is:

```text
for every epsilon>0,
|S_n(s0)| <= (1+epsilon)^n
for all sufficiently large n.
```

A polynomial bound would be much stronger than required.

This is an **equivalent reformulation**, not a proof of RH.

### Step 5 — identify the pole subtraction with the prime-counting discrepancy

Let

```text
f_n(x) = x^(-s0) L_(n-1)^(1)(A log x),
psi(x) = sum_{m<=x} Lambda(m).
```

Then

```text
P_n = A integral_[1,infinity) f_n(x) d psi(x).
```

The continuous main-density integral is exactly the pole sequence:

```text
A integral_1^infinity f_n(x) dx = 1-q^n.
```

Proof: put `t=A log x` and `p=(s0-1)/A`. The integral becomes

```text
integral_0^infinity e^(-p t) L_(n-1)^(1)(t) dt.
```

Using the Laguerre generating function and extracting the coefficient gives

```text
1 - [(p-1)/p]^n.
```

But

```text
(p-1)/p = -s0/(s0-1) = q.
```

Hence

```text
S_n(s0)
 = A integral_[1,infinity)
     x^(-s0) L_(n-1)^(1)(A log x)
     d(psi(x)-x).
```

This is the exact object that future work must estimate. The deterministic prime-density main term has been removed before any asymptotics are used.

### Step 6 — derive the exact finite-difference filter

Let the forward-shift operator be

```text
(E a)_n = a_(n+1).
```

Because

```text
h_n = 1-q^n,
```

the degree-two filter

```text
T = (E-1)(E-q)
```

annihilates the entire pole sequence exactly:

```text
T h_n = 0.
```

Therefore

```text
T P_n = T S_n.
```

DLMF 18.9.13 gives the Laguerre contiguous relation

```text
L_n^(0)(x) = L_n^(1)(x) - L_(n-1)^(1)(x).
```

With

```text
K_n(x) = L_(n-1)^(1)(x),
```

we have

```text
(E-1)K_n = L_n^(0)(x),
```

and therefore

```text
T K_n
 = (E-q)L_n^(0)(x)
 = L_(n+1)^(0)(x) - q L_n^(0)(x).
```

So the filtered prime trace has the exact absolutely convergent formula

```text
T P_n
 = A sum_{m>=2} Lambda(m)m^(-s0)
     [L_(n+1)^(0)(A log m)
      - q L_n^(0)(A log m)].
```

For every fixed `n`, this series is absolutely convergent.

### Step 7 — verify that the filter cannot erase a nontrivial off-line zero

For a coefficient sequence with generating function `F(z)=sum a_n z^(n-1)`, applying `E-c` multiplies the singular part of the generating function by `1-cz` (up to powers of `z` and initial-data polynomials, which do not create or remove nonzero interior singularities).

Thus `T` can cancel an interior pole only at

```text
z=1
```

or

```text
z=1/q=z(1).
```

`z=1` corresponds to no finite `s`, and `z=1/q` corresponds to `s=1`, not to a nontrivial zeta zero.

Hence a pole produced by any nontrivial zero `rho` with `Re(rho)>1/2` survives the filter.

Accordingly,

```text
RH
<=> limsup |T P_n|^(1/n) <= 1.
```

The direct pole-subtracted criterion `S_n` is simpler and is therefore the primary formulation; `T P_n` is retained as an exact alternative when discrete cancellation is analytically useful.

## Circularity check

The sequence bound

```text
limsup |S_n|^(1/n) <= 1
```

is **exactly equivalent to RH**. It must therefore never be inserted as an assumption or described as an independently known estimate.

The gain from this attempt is structural, not a proof:

1. it removes the deterministic `s=1` pole contribution exactly;
2. it converts the remaining target into a prime-discrepancy transform;
3. it prevents future work from wasting effort trying to prove the impossible raw bound `P_n=exp(o(n))`;
4. it gives a minimal exact object whose exponential growth is caused only by zeros in `Re(s)>1/2`, not by the zeta pole.

The square-root pointwise estimate for `psi(x)-x` from `C-0004` remains forbidden as an input because it is already RH-equivalent.
